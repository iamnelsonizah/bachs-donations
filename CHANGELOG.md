# Changelog

## 0.4.0

- Replaced the editor-first fundraiser flow with a focused, accessible modal builder and live preview.
- Added per-form colors, layout and corner styles, button text, optional donor name and phone fields, campaign image selection, and custom donor questions.
- Added a clear Bachs Payment Setup screen for Sandbox/Live credentials, webhook configuration, and connection status.
- Improved the Fundraising dashboard and forms list so a first-time administrator can create, publish, and share a form without opening the default WordPress editor.
- Added donor phone and custom response handling to checkout, the donation ledger, CSV reports, privacy export, and erasure.
- Updated the installation, payment setup, and form creation guides for the new workflow.

## 0.3.0

- Replaced donation amount dropdowns with accessible, currency-aware suggested amount cards and inline validation.
- Added date-filtered fundraising analytics with USD and NGN totals kept separate, daily trends, top forms, and protected CSV export.
- Improved dashboard shortcuts, reports guidance, and admin page styling.
- Updated the README and WordPress readme with report and donor-flow instructions.

## 0.2.0

- Added a Donation Forms editor with per-form currencies, payment methods, default currency, suggested amounts, custom amount toggle, and optional fundraising goal.
- Published forms now have their own public donation page, with an optional goal progress indicator.
- Donation records now retain the associated form ID and title, and the admin ledger displays the form.
- Added a Fundraising dashboard with onboarding steps, status, and summary counts.
- Added per-form payment method controls and confirmed-gift totals on the Donation Forms list.
- Added a payment gateway contract and Bachs adapter for checkout, reconciliation, webhook verification, and event normalization.
- Added responsive, accessible donation form styling and currency-aware amount presets.
- Updated the README and WordPress readme with form creation and publishing instructions.

## 0.1.0

- Initial standalone donation plugin release.
- Added hosted USD and NGN one-time donation checkout.
- Added signed webhook verification, ledger, reconciliation, and WordPress privacy hooks.
