# Changelog

## 0.2.0

- Added a Donation Forms editor with per-form currencies, payment methods, default currency, suggested amounts, custom amount toggle, and optional fundraising goal.
- Published forms now have their own public donation page, with an optional goal progress indicator.
- Donation records now retain the associated form ID and title, and the admin ledger displays the form.
- Added a Fundraising dashboard with onboarding steps, status, and summary counts.
- Added per-form payment method controls and confirmed-gift totals on the Donation Forms list.
- Added a payment gateway contract and Bachs adapter for checkout, reconciliation, webhook verification, and event normalization.
- Added responsive, accessible donation form styling and currency-aware amount presets.
- Updated the README and WordPress readme with form creation and publishing instructions.

## 0.1.0

- Initial standalone donation plugin release.
- Added hosted USD and NGN one-time donation checkout.
- Added signed webhook verification, ledger, reconciliation, and WordPress privacy hooks.
